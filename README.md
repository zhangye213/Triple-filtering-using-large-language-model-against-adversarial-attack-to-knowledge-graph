Faithful KG-RAG: A Robust LLM-Augmented Framework
This repository contains the implementation of the framework presented in the dissertation Faithful KG-RAG: A Robust LLM-Augmented Framework for Question Answering under Knowledge-Graph Poisoning.
Knowledge-graph question answering (KGQA) is susceptible to fine-grained poisoning attacks, such as edge poisoning, which can derail otherwise correct multi-hop reasoning. Faithful KG-RAG serves as a protective layer that assumes the reasoning LLM acts like an expert adjudicator operating on a path-centric, purified scan of the knowledge graph.
Core Pipeline
Our framework functions through a highly structured, multi-stage pipeline designed to filter noise and identify adversarial data:
	• Stage 1 - Relation Path Generation: The system utilizes offline relation-path hypotheses generated by models such as RoG.
	• Stage 2 - Path-Constrained Grounding: The online pipeline performs relation-constrained grounding directly on the polluted local graph.
	• Stage 3 - Path-Focused Context Purification: The system prepares a highly focused context that is made up of on-path triples only.
	• Stage 4 - Strict LLM Adjudication: The reasoning LLM is queried in a strict in-set selection manner to deduce the verified correct answer.
	• Stage 5 - Poisoned Facts Detection (Attribution): The framework flags and poisonifies triples that lie on grounded paths where the tail does not match the LLM's verified answer.
	• Stage 6 - Graph Healing: The detected poisoned set is removed to derive a sanitized (filtered) subgraph.
	• Stage 7 - Re-generation: The system re-applies the offline path hypotheses on the sanitized graph using the base predictor to output a fully recovered answer.
Key Performance Results
	• Faithful KG-RAG achieves 76.77 Hits@1 and 70.40 F1 on the poisoned WebQSP dataset.
	• The framework significantly outperforms the Naive RoG baseline, which drops severely to 32.1 Hits@1 when undefended.
	• Following the graph sanitization process, the Naive RoG baseline successfully recovers to 68.0 Hits@1, reaching close to the clean upper bound of 74.32.
	• The built-in poisoned triples detection algorithm attains a 90% precision and a 74% recall.
System Features
	• The entire framework is strictly model-agnostic, auditable, and easily compatible with existing KGQA stacks.
	• It effectively recovers systemic reliability under data corruption while providing detailed interactive inspection and high reproducibility.
	• The architecture includes an end-to-end interactive demonstrator that exposes internal prompts, text streams, and intermediate artifacts.
