2. Core Problem: Subtle KG Poisoning

Threat Model

Adversary rewires a triple tail: (h, r, t) → (h, r, t′); local coherence preserved.

Heuristics miss it; giving the entire noisy subgraph to LLM hurts performance.

Attack Illustration
Head → Rel r → Correct t ✓
Injected edge
Head → Rel r → Wrong t′ ✗

5. Core Mechanisms (I)

Context Purification

Build a focused subgraph from grounded paths only—cut noise, keep evidence.

Effect: Less distraction, more faithful reasoning.

Strict Adjudication

LLM must pick from candidate set only. Prevents out-of-candidate hallucination.

Effect: Traceable, machine-checkable outputs.

6. Core Mechanisms (II)

“AI Detective” (Attribution)

Any grounded path whose tail is rejected by the final answer → its triples are flagged.

Healing & Re-answer

Remove flagged triples → rerun original RoG on the filtered graph to validate recovery.
